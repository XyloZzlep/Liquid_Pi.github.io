About

Una laptop hecha para empezar

Liquid-Pi nació de una pregunta: ¿qué se puede hacer con una Raspberry Pi que no esté ya hecho? La respuesta fue un computador portátil de bajo costo para quienes dan sus primeros pasos en la informática: ofimática, navegación, programación por bloques y desarrollo de software, con un escritorio ligero y aplicaciones propias.

  • Raspberry Pi 4
  • Xfce
  • Scratch
  • Rust
